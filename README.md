# 图提取 ImageGrab · 电商图片下载插件

一键提取淘宝、京东、拼多多商家版商品详情页的所有图片，集中预览、按需勾选、批量下载为 PNG。

## 项目结构

```
├── manifest.json      # 插件清单（Manifest V3）
├── content.js         # 注入悬浮按钮 + 提取图片
├── content.css        # 按钮样式
├── background.js      # Service Worker：消息转发、图片转 PNG、下载
├── gallery.html       # 图片预览页（结构）
├── gallery.css        # 图片预览页（样式）
├── gallery.js         # 图片预览页（逻辑：展示/勾选/下载）
├── assets/            # 插件图标 icon16/48/128.png
└── docs/              # 插件官方宣传网站（纯静态，双击即可打开）
    ├── index.html
    ├── css/style.css
    └── js/main.js
```

---

## 一、安装插件

1. 下载并解压本项目到本地文件夹（记住路径）。
2. 打开 Chrome，地址栏输入 `chrome://extensions` 回车。
3. 打开右上角的「**开发者模式**」开关。
4. 点击「**加载已解压的扩展程序**」，选择解压后的项目根文件夹。
5. 安装完成，工具栏会出现「图提取」图标。

## 二、使用插件

1. 打开淘宝 / 京东 / 拼多多商家版的**商品详情页**。
2. 页面右下角会出现悬浮按钮「**获取图片**」。
3. 点击按钮，插件自动扫描并提取页面所有商品图。
4. 自动打开「图提取 · 图片预览」页面，网格展示所有图片。
5. 勾选要下载的图片（支持全选 / 反选），点击「**下载选中**」。
6. 图片统一转为 PNG，按 `商品图_001.png`、`商品图_002.png`… 自动编号保存到浏览器默认下载目录。

## 三、支持平台与匹配域名

| 平台 | 匹配域名 |
| --- | --- |
| 淘宝 | `*://*.taobao.com/*`、`*://*.tmall.com/*` |
| 京东 | `*://*.jd.com/*` |
| 拼多多商家版 | `*://*.pinduoduo.com/*`、`*://*.yangkeduo.com/*` |

## 四、官网预览与自定义

官网位于 `docs/` 文件夹，纯静态，**双击 `docs/index.html` 即可在浏览器打开预览**。

- **修改主色调**：编辑 `docs/css/style.css` 开头的 `:root` 变量，替换 `--primary`、`--primary-2` 即可全局换肤。
- **修改文案**：编辑 `docs/index.html` 中对应区块文字，以及 `docs/css/style.css` 的样式。

## 常见问题

- **页面没有出现「获取图片」按钮？** 请确认当前是商品详情页，且插件已启用；刷新页面后按钮会重新注入。
- **图片下载失败？** 部分平台有防盗链，插件已在 Service Worker 中通过 `fetch + createImageBitmap` 处理跨域转换，请确认 `host_permissions` 未被浏览器拦截。
- **想临时关闭按钮？** 在 `chrome://extensions` 中停用插件即可。
