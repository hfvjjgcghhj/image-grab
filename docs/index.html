三步安装，立即可用

无需账号，无需编译，加载本地文件夹即可使用。

  1. 1

    下载插件压缩包并解压

    将压缩包解压到本地文件夹，记住这个文件夹的位置。

  2. 2

    打开 Chrome 扩展管理页

    地址栏输入 chrome://extensions 并回车。

  3. 3

    开启「开发者模式」

    点击页面右上角的 开发者模式 开关。

  4. 4

    加载已解压的扩展程序

    点击 加载已解压的扩展程序，选择刚才解压的文件夹即可完成安装。
